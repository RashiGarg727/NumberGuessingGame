# Number Guessing Game 🎯

A simple Number Guessing Game built using HTML and JavaScript.

## 🚀 Features
- Random number generation
- User input checking
- Win/lose messages
- Interactive gameplay

## 🛠️ Tech Stack
- HTML
- JavaScript

## 📌 How to Play
1. Enter a number.
2. Click the check/submit button.
3. Try to guess the correct number.
4. The game gives hints if the guess is too high or too low.
